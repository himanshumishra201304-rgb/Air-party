# AirParty

TV as screen · phones as controllers · PeerJS party games.

## Live site

Enable GitHub Pages:
1. Repo **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / **root**
4. Save

Then open:

**https://himanshumishra201304-rgb.github.io/Air-party/**

## How to play

1. Open the site on TV/laptop → **TV / Big Screen**
2. Open the same site on phones → **Mobile Controller**
3. Enter the 4-digit code (or scan QR)

Works best in Chrome / Edge.
